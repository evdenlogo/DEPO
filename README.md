# Google Harita SEO Planlayıcı (Basit Arayüz)

Bu proje, Google Haritalar odaklı **güvenli/white-hat** yerel SEO adımlarını
hızlı planlamak için hazırlanmış tek sayfalık, basit bir web arayüzüdür.

## Özellikler

- İşletme bilgilerini alma (ad, lokasyon, ana hizmet)
- Kontrol listesine göre otomatik SEO puanı hesaplama
- Eksik alanlara göre öncelikli haftalık aksiyon planı üretme
- Sıfırlama ile hızlı tekrar kullanım

## Çalıştırma

Herhangi bir web sunucusu ile çalıştırabilirsiniz:

```bash
python3 -m http.server 8000
```

Ardından tarayıcıda:

`http://localhost:8000`

## Not

Bu araç Google politikalarını ihlal eden spam/sahte yöntemleri önermez.
Gerçek müşteri deneyimi ve sürdürülebilir optimizasyon odaklıdır.
